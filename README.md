# SkyWatch

SkyWatch is an astronomy-focused project that aims to integrate astronomical events, observation locations, and weather data to help users plan sky observations.

## Project Structure

```text
skywatch/
├── backend/        
├── data-model/     # XML and JSON data processing
├── docs/           
├── frontend/       
└── README.md
```

For more information about the data processing component, see the [Data Model README](data-model/README.md).
