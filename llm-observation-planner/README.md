# SkyWatch AI – LLM Observation Planner

SkyWatch AI is an AI-powered astronomical observation planner developed as a standalone module of the **SkyWatch** project. It combines dynamically retrieved astronomical events with personalized recommendations generated by a large language model (LLM).

## Features

- **Astronomical Events:** Discover upcoming events using the SpaceCatalog API and custom date filters.
- **Observation Locations:** Generate location suggestions based on the selected event, starting location, travel distance, transportation method, and observation priorities.
- **Equipment Recommendations:** Receive equipment suggestions based on experience, available equipment, and observation preferences.
- **Observation Plans:** Generate step-by-step observation plans tailored to the selected event and user preferences.
- **Event Facts:** Explore scientific explanations and interesting facts about astronomical events.

## Technologies

- **Backend:** Python, FastAPI, Pydantic
- **Frontend:** HTML, CSS, JavaScript
- **LLM Provider:** OpenRouter
- **LLM:** NVIDIA Nemotron (configurable)
- **Astronomical Data:** SpaceCatalog API
- **Testing:** pytest

## LLM Integration

The application dynamically constructs prompts using astronomical event data and user inputs. Each AI feature uses dedicated instructions and a corresponding JSON response schema.

LLM responses are generated in structured JSON format, validated and deserialized into Pydantic models, and displayed through the web interface.

The API key is stored in environment variables and is never exposed to the frontend.

## Setup and Usage

**1. Create and activate a virtual environment**

From the `llm-observation-planner/backend/` directory:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**2. Install dependencies**

```powershell
python -m pip install -r requirements.txt
```

**3. Configure OpenRouter**

Copy `.env.example` to `backend/.env` and set your OpenRouter API key and preferred model.

```env
OPENROUTER_API_KEY=your_api_key
OPENROUTER_MODEL=nvidia/nemotron-3.5-super-vl:free
```

**4. Start the backend**

From `backend/`:

```powershell
uvicorn app.main:app --reload --port 8000
```

**5. Start the frontend**

Open a second terminal in `llm-observation-planner/frontend/`:

```powershell
py -m http.server 5500 --bind 127.0.0.1
```

Open **http://127.0.0.1:5500/** in your browser.

The interactive API documentation is available at **http://127.0.0.1:8000/docs**.

## Testing

Run the automated test suite from `backend/`:

```powershell
python -m pytest tests/
```

The test suite covers data validation, dynamic prompt construction, API endpoints, and error handling. External services are mocked during automated API testing.

## External Services

- [SpaceCatalog API](https://spacecatalog.org/) – astronomical events and event details.
- [OpenRouter](https://openrouter.ai/) – LLM access and structured JSON generation.
